# Архитектурные решения (ADR)

Одно решение — один файл `NNN-название.md` (например, `001-yaml-config.md`), номера по порядку.

Структура файла:

- **Контекст** — какая проблема, какие требования затронуты (FR-xx, NFR-xx, D-xx).
- **Решение** — что выбрали.
- **Альтернативы** — что рассматривали и почему отклонили.

После принятия решения поправь затронутые разделы `requirements.md` или `architecture.md`.
