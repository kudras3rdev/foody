# 002. Состав eval этапа 1 и неизвестные блюда

## Контекст

В стартовой гипотезе по моделям (requirements.md) четыре задачи, включая «Неизвестное блюдо» (GPT-4o через GitHub Models), а в конфиге (architecture.md, 5.2) задач три. Неясно, какие задачи прогоняет eval этапа 1 (FR-20).

## Решение

1. Eval этапа 1 прогоняет две задачи: `label_extraction` и `meal_recognition`.
2. Неизвестное блюдо — это не отдельная задача, а ветка `meal_recognition`: модель не нашла кандидата и вернула `new_item` с оценкой (источник `llm_estimate`, уровень `low`). GPT-4o — кандидат в цепочку `meal_recognition`, сравнивается на случаях «кафе и неизвестные блюда». GitHub Models закрыт, GPT-4o берём через OpenRouter (ADR 005).
3. `text_parse` (`TextParser`, FR-02) остаётся на этапе 2 и в eval этапа 1 не входит.

## Альтернативы

- **Отдельная задача `unknown_dish`.** Отклонено: заранее неизвестно, найдётся ли кандидат, поэтому пришлось бы вызывать модель дважды (сначала опознание, потом оценку). Это удваивает задержку и расход бесплатных лимитов.
