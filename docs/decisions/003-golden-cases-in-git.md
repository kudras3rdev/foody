# 003. Эталоны золотого набора в git

## Контекст

Каталог `data/` не коммитится (фото, БД, отчёты). Но `data/golden/cases.yaml` — это неделя ручной работы по эталонам, файл маленький и без личных данных, кроме описаний еды. Потерять его дороже, чем хранить.

## Решение

`data/golden/cases.yaml` коммитится в git. Фото набора, БД и отчёты eval не коммитятся. Это реализует исключение в `.gitignore`.

## Альтернативы

- **Не коммитить, полагаться на бэкап.** Отклонено: бэкап появится только на этапе 2 (NFR-06), а набор собирается уже сейчас.
- **Коммитить и фото.** Отклонено: десятки мегабайт бинарников в истории git. Фото остаются локально, а с этапа 2 — в бэкапе.
