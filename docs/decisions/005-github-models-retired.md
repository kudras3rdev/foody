# 005. GitHub Models закрыт, его место занимает OpenRouter

## Контекст

GitHub Models полностью закрыт 30 июля 2026 года ([changelog](https://github.blog/changelog/2026-07-30-github-models-is-now-retired/)). Проверка 26.10.2026 показала: `models.github.ai` на любой запрос, даже без токена, отвечает HTTP 200 с телом `OK`. Через GitHub Models в стартовой гипотезе шёл GPT-4o для неизвестных блюд, а в рисках он был запасным провайдером на случай блокировки Gemini.

## Решение

1. Провайдер `github` убран из конфига, документации и `.env.example`.
2. Его роль берёт OpenRouter (`https://openrouter.ai/api/v1`, ключ `OPENROUTER_API_KEY`), он перестаёт быть необязательным. Через него доступны бесплатные vision-модели с суффиксом `:free` и платный GPT-4o. Бесплатный список часто меняется, поэтому актуальные модели берём из `GET /api/v1/models` перед eval.
3. Кандидат для неизвестных блюд — GPT-4o через OpenRouter (платно) или лучшая бесплатная vision-модель OpenRouter. Решает eval (D-09).

Клиент проверен на OpenRouter 26.10.2026: изображение и JSON-режим работают (`nvidia/nemotron-3.5-super-vl:free`).

## Альтернативы

- **Microsoft Foundry (рекомендация GitHub).** Отложено: нужна подписка Azure и отдельная регистрация, бесплатного уровня, сравнимого с GitHub Models, нет.
- **Прямой ключ OpenAI.** Отложено до платного режима (C-05): оплата иностранной картой, тот же GPT-4o через OpenRouter доступен без отдельного аккаунта.
